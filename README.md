# 停车轨迹实验室 v0.3 · vivo X200 Pro 试验版

**目的**：通过真实数据检验「手机自身传感器 + 车辆低速运动约束」在 GNSS 失效后能够维持多少秒、多少米的可用水平定位。此 App 不是正式寻车导航，不使用真实车库地图，不接入 CAN/轮速，不上传云端。

## v0.3 的驾车模式

* **蓝线（车辆模型）**：GNSS 可靠且有有效速度/方向时初始化，之后使用水平加速度推算速度、使用陀螺仪世界竖轴角速度推算转向，应用低速车辆约束（速度非负、转向连续、不能瞬间横移）。
* **紫色虚线（恒速基线）**：使用最近一次可靠 GNSS 车速，之后不利用加速度更新速度，但会利用陀螺仪更新转向。对比蓝线更容易看出复杂算法是否真的改善误差。
* **绿色散点（GPS 观测）**：用来和模型对照，GPS 本身也有多路径误差。可通过图层开关打开。
* **橙色原始积分**：用于展示直接积分加速度的漂移，默认隐藏，不用于定位。

未获得可靠的 **GPS 运动方向和车速**时，车辆模型**不会假装知道车往哪里开**；地图蓝点应停留在初始化状态。静止时的 GPS 方向不作为有效航向。低加速度可能是匀速行驶，因此**不会仅凭「加速度很小」判断车辆停下**；高质量 GNSS 近零速度可用于零速校正。

## 室外「模拟 GPS 断联」流程（重点测试）

1. **停好车后**打开 App，选择「驾车实验」，勾选「模拟 GPS 断联」；手机固定在支架上，不能在测试过程中转动/拿起。
2. 在开阔、安全、GPS 良好的普通道路启动记录后正常行驶。只有在连续 **15 秒**接收到满足速度和方向精度要求的移动 GNSS 观测后，App 才自动开始断联模拟。
3. **断联 120 秒**期间，App 继续收集 GPS 原始观测作为对照，但**绝不用于蓝线和紫线的校正**。届时显示每个模型的当前误差，并在 30/60/120 秒记录一次误差。
4. 结束后停车，再操作 App 结束记录，导出 CSV。**任何操作均应在停车时完成**，不能为触发测试而在驾驶中触屏。
5. 可以在室外重复多次，不同路线分别尝试低速直行、平稳转弯和停车等情况。将 CSV 和实际路线描述发回进行误差分析。

注意：若 GPS 参考点不够精确或持续更新中断，对照误差没有可靠真值；某些时间段的误差会显示「—」。自动 15 秒计时可能因 GPS 速度/方向不稳定而重新开始。模拟断联测试结束时从下一次有效 GPS 恢复校正。

## 地下车库实验

不勾选「模拟 GPS 断联」。在地面启动并建立 GNSS 车速、航向校准，再进入车库；没有可靠 GPS 时模型会继续推算，但**这并不代表其真实精度足以找车**。务必自己记下实际车位位置用于离线评估。

## 室内步行实验

步行模式按检测到的有效步数与指定步长估算位移，**GPS 观测不会修改步行蓝线**。无需 GPS 即可做相对轨迹实验，但步行方向依赖手机姿态。该模式无法代表车辆运动模型的效果。

## 构建与权限

- Android Studio / JDK 17；Gradle 8.12；AGP 8.9.2；compileSdk 35；Android 8.0 起。
- 打开本工程后运行 `gradle :app:assembleDebug`，调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
- 也可打开仓库 GitHub Actions → **Build debug APK** 的成功记录，下载 APK 制品 ZIP，解压后安装。
- 首次使用授权精确定位、运动识别及通知权限；需要系统定位开关开启。采用前台服务/唤醒锁，仍需在 vivo 真机验证锁屏、息屏、后台省电策略。
- 所有 CSV 记录保存在 App 私有 Documents/sessions 目录，通过「导出最近一次 CSV」分享；卸载应用前请备份 CSV。
- **车机/轮速没有接入。** 由于缺乏绝对速度来源，GNSS 断联后的速度误差仍会随时间累积，车辆约束仅减少部分不合理轨迹。

## 数据字段说明

和 v0.2 相同的 CSV 主列：`elapsed_s,elapsed_realtime_ns,wall_time_ms,event,x,y,z,w,latitude,longitude,gps_accuracy_m,east_m,north_m,raw_east_m,raw_north_m,speed_mps,heading_deg,note`。

- `DR_MODEL`：模型推算与恒速基线的坐标、速度、角速度等信息。
- `GPS_REFERENCE`：断联模拟中保留的 GNSS 对照坐标（x=东向，y=北向），z=车辆模型到 GNSS 参考的距离，w=恒速模型到 GNSS 参考的距离；时间写在 note。
- `BLACKOUT_START`, `BLACKOUT_END`：自动测试时间界限；`GPS`：GNSS 原始观测（x/y 为纬度/经度，note 包含车速/方位角精度）。
- 30/60/120 秒误差只代表该时刻与 **GNSS 观测**之间的差值，并不等于有高精度真值设备验证的误差。
